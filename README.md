# 东京，读不懂的空气（Tokyo Quest）

一款**零基础日语互动故事游戏**。你扮演刚到东京的中国 AI 工程师小光，一句日语都不会，却要靠"开口说日语"在这个读不懂空气的城市里活下去、证明自己。

（浏览器直接打开，无需安装，手机/电脑都能玩）

## 这是什么

- **类型**：互动故事 / 视觉小说（浏览器端）
- **语言**：日语原文 + 罗马字注音 + 中文翻译，三层对照
- **面向**：纯零基础日语学习者（没学过五十音也能玩）
- **体量**：EP01 共 74 个剧情节点、10 个场景，约 8-10 分钟

## 玩法

**核心机制：语言能力 = 剧情推进力。**

1. 每个剧情节点给你几个日语选项，选一个"说"出来，剧情就往下走。
2. 选错不惩罚——NPC 会放慢语速、用更简单的词重说。
3. 说不出来时，永远有「わかりません」（我听不懂）可以选。
4. 你选的每句话会自动用男声朗读（读完才推进），听一遍再往下走。

## 本集重点表达

| 表达 | 罗马音 | 意思 |
|------|--------|------|
| すみません | sumimasen | 对不起 / 不好意思 |
| ありがとうございます | arigatō gozaimasu | 谢谢 |
| はい | hai | 是 / 好的 |
| わかりません | wakarimasen | 我听不懂 |
| わかりました | wakarimashita | 好的 / 明白了 |

| よろしくお願いします | yoroshiku onegai shimasu | 请多关照 |
| お疲れさまです | otsukaresama desu | 辛苦了 |

## 剧情（无剧透）

你（小光）刚到东京入职一家 IT 公司，负责一个 AI 广告项目。对接你的女同事高桥葵活泼热情，前辈藤堂诚笑容客气。你在问路、欢迎会、跑客户里学会开口说日语。但项目演示那天，有人把锅甩给了你——不会日语的你，连替自己辩解都开不了口。要洗清冤屈，只有一个办法：和葵假扮恋人，出席那场必须携伴参加的招待会。

## 制作 SOP

完整的制作流程方法论见 [`SOP.md`](SOP.md)，核心两条原则：
1. **语言能力 = 剧情推进力**（不是为了学而学，是不会语言就出事）
2. **每集聚焦一批高频核心表达并真正用起来**（学了就要用，是语言习得的关键）

## 技术说明

- 数据模型：日语原文 / 中文翻译 / 罗马字注音，内嵌在剧情 JSON
- 双引擎：Python + JavaScript 各一份状态机，逻辑逐字段一致
- 素材：53 张场景图/立绘（AI 生成）、116 句配音（5 个声线）
- 存档：进度保存在浏览器 localStorage
